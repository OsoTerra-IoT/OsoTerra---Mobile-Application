# OsoSense Mobile App (APK de prueba)

Build `debug` de la rama `develop`, conectado al Backend en Render (https://ososense-backend.onrender.com).

1. Descarga `ososense-app-movil.apk` en un celular Android.
2. Permite "Instalar apps desconocidas" para el navegador o el gestor de archivos.
3. Abre el archivo e instala.
